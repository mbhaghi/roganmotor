# ۲. مرجع استانداردها — API، ILSAC، ACEA، JASO و تأییدیه‌های خودروساز

> این سند «جدول مرجع» تیم است: هم برای تولید محتوا، هم برای پر کردن فیلدهای محصول در دیتابیس،
> هم برای ابزار روغن‌یاب. هر ادعایی که روی سایت می‌نویسیم باید در این جداول ریشه داشته باشد.

## ۲.۱ API — مؤسسهٔ نفت آمریکا

### دسته‌های بنزینی (S = Spark)

| دسته | سال | وضعیت |
| --- | --- | --- |
| SJ | ۱۹۹۷ | منسوخ |
| SL | ۲۰۰۱ | منسوخ ولی در بازار ایران هنوز رایج |
| SM | ۲۰۰۴ | منسوخ |
| SN | ۲۰۱۰ | قدیمی‌تر، برای موتورهایی که برای آن طراحی شده‌اند قابل قبول |
| **SN Plus** | ۱ مهٔ ۲۰۱۸ | پل موقت؛ فقط تست LSPI (Sequence IX) را به SN اضافه کرد |
| **SP** | ۱ مهٔ ۲۰۲۰ | **استاندارد جاری** |

**API SP چه چیزی اضافه کرد؟**
- تست **Sequence IX** برای LSPI با حدود سخت‌گیرانه‌تر
- تست **Sequence X** برای **سایش زنجیر تایم** (۲۱۶ ساعت کارکرد واقعی) — چیزی که SN Plus نداشت
- تست **Sequence IVB** برای سایش مجموعهٔ سوپاپ (جایگزین IVA، سخت‌تر)
- تست **Sequence IIIH** برای اکسیداسیون و رسوب (داغ‌تر و طولانی‌تر از IIIG)
- **سازگاری رو‌به‌عقب کامل** با SN Plus، SN، SM، SL

> **پیام بازاریابی دقیق:** «API SP جای SN Plus را گرفت و تمام الزامات قبلی را پوشش می‌دهد.
> اگر دفترچهٔ خودروی شما SN یا SN Plus خواسته، SP یک ارتقای مستقیم و ایمن است. اما اگر
> دفترچه SP خواسته، SN Plus کافی نیست و می‌تواند گارانتی موتور را باطل کند.»

### دسته‌های دیزلی (C = Compression)

| دسته | کاربرد |
| --- | --- |
| CF / CF-2 / CF-4 | قدیمی، منسوخ |
| CH-4 | ۱۹۹۸ |
| CI-4 / CI-4 PLUS | ۲۰۰۲/۲۰۰۴ — پرکاربرد در ناوگان قدیمی ایران |
| CJ-4 | ۲۰۰۶ — برای موتورهای دارای DPF |
| **CK-4** | ۲۰۱۶ — سازگار رو‌به‌عقب، HTHS ≥ ۳٫۵، برای اکثر دیزل‌های سنگین |
| **FA-4** | ۲۰۱۶ — HTHS بین ۲٫۹ تا ۳٫۲، **سازگار رو‌به‌عقب نیست**، فقط موتورهای طراحی‌شده برای آن |

> CK-4 و FA-4 هر دو از دستهٔ PC-11 آمدند. FA-4 برای صرفه‌جویی سوخت است و **نباید** در
> موتور قدیمی ریخته شود. این یکی از پرتکرارترین اشتباهات ناوگان است.

### نمادهای API روی قوطی
- **Donut (دونات)**: کلاس سرویس در مرکز (SP / CK-4)، گرید SAE، و عبارت «Energy/Resource Conserving»
- **Starburst (ستاره)**: گواهی ILSAC
- **Shield (سپر)**: نماد جدید مخصوص **ILSAC GF-6B** (فقط 0W-16)

## ۲.۲ ILSAC — کمیتهٔ مشترک آمریکا و ژاپن

| استاندارد | API معادل | گریدها | توضیح |
| --- | --- | --- | --- |
| GF-5 | SN Plus | — | نسل قبل |
| **GF-6A** | SP | 0W-20، 5W-20، 0W-30، 5W-30، 10W-30 | سازگار رو‌به‌عقب با GF-5؛ علامت Starburst |
| **GF-6B** | SP | **فقط 0W-16** | سازگار رو‌به‌عقب **نیست**؛ علامت Shield |

تفاوت API با ILSAC: **ILSAC علاوه بر حفاظت موتور، مصرف سوخت را هم تست می‌کند؛ API نمی‌کند.**
پس `API SP` ≈ حفاظت، و `ILSAC GF-6` = `API SP` + اقتصاد سوخت + تست‌های تکمیلی زنجیر تایم.

## ۲.۳ ACEA — انجمن خودروسازان اروپا

### ساختار نسخه‌ها (خیلی مهم برای به‌روز بودن محتوا)

| نسخه | حوزه | اولین مجاز بودن ادعا | الزامی برای ادعای جدید | قابل بازاریابی تا |
| --- | --- | --- | --- | --- |
| ۲۰۱۶ | همه | ۱ دسامبر ۲۰۱۶ | ۱ دسامبر ۲۰۱۷ | منسوخ |
| ۲۰۲۱ | فقط سبک | ۱ مهٔ ۲۰۲۱ | ۱ مهٔ ۲۰۲۲ | ۱ اوت ۲۰۲۵ (منسوخ) |
| ۲۰۲۲ | فقط سنگین | ۱ مهٔ ۲۰۲۲ | ۱ مهٔ ۲۰۲۳ | ۱ اکتبر ۲۰۲۶ (دیگر جاری نیست) |
| **۲۰۲۳** | **سبک — نسخهٔ جاری** | ۱۲ سپتامبر ۲۰۲۳ | ۱۲ سپتامبر ۲۰۲۴ | — |
| **۲۰۲۴ Rev.1** | **سنگین — نسخهٔ جاری** | ۱ اکتبر ۲۰۲۴ | ۱ اکتبر ۲۰۲۵ | — |

> ACEA خودش روغن را تأیید یا مجوز نمی‌دهد. تولیدکننده **خوداظهاری (Self-certification)** می‌کند
> و باید تحت سامانهٔ کیفی **EELQMS** (مشترک ATIEL/ACEA/ATC) عمل کند. این تفاوت مهمی است با
> «تأییدیهٔ رسمی خودروساز» که واقعاً تست و مجوز دارد. **این نکته را در سایت صریح بگویید** —
> یک نشانهٔ تخصص است.

### مفهوم SAPS — چیزی که مشتری نمی‌فهمد ولی باید بفهمد

**SAPS = S**ulphated **A**sh + **P**hosphorus + **S**ulphur.

فیلتر ذرات (DPF/GPF) فقط **دوده** را می‌سوزاند؛ **خاکستر** را هرگز نمی‌تواند حذف کند.
خاکستر روغن به‌صورت برگشت‌ناپذیر در فیلتر انباشته می‌شود و عمر آن را کوتاه می‌کند.
فسفر و گوگرد هم کاتالیزور سه‌راهه (TWC) را مسموم می‌کنند.

**قانون ساده برای سایت:**
> اگر خودرو DPF یا GPF دارد → فقط کلاس **C**. کلاس A/B ممنوع، حتی اگر ویسکوزیته درست باشد.

## ۲.۶ خلاصهٔ یک‌خطی برای تیم فروش/پشتیبانی

```
ویسکوزیته (SAE)   → «چقدر روان است»   → پنجرهٔ مجاز، نه مجوز کیفیت
کلاس API          → «سطح فناوری»        → سازگار رو‌به‌عقب (به‌جز FA-4 و GF-6B)
کلاس ACEA         → «کف کیفیت اروپایی»  → C برای DPF/GPF، A/B بدون آن
تأییدیهٔ OEM      → «سقف الزام»         → همان چیزی که دفترچه خواسته
```

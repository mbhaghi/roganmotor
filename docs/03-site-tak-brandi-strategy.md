# ۳. سایت فروش تک‌برندی روغن موتور باید چه کار کند؟

> سؤال اصلی: وقتی فقط **یک برند** می‌فروشیم، سایت چه وظیفه‌ای دارد که یک فروشگاه چندبرندی
> (مثل ترب/دیجی‌کالا/فروشگاه‌های عمومی روانکار) ندارد؟
> پاسخ کوتاه: **سایت تک‌برندی نباید «فروشگاه» باشد؛ باید «مرجع و نقطهٔ اعتماد» باشد.**

---

## ۳.۱ اول تعریف کنیم: «تک‌برندی» یعنی چه؟ (سه سناریوی کاملاً متفاوت)

| سناریو | شما کیستید | پیامد استراتژیک |
| --- | --- | --- |
| **A. سایت رسمی خودِ برند (brand.com)** | مالک برند / تولیدکننده | کنترل کامل قیمت، تصویر، داده؛ هدف = برندسازی + D2C + حمایت از شبکهٔ نمایندگی (نه جنگ با آن) |
| **B. نمایندگی/عامل رسمی یک برند** | فروشندهٔ مجاز، برند مال دیگری است | مزیت اصلی = **اصالت + فاکتور رسمی + خدمات**؛ باید گواهی نمایندگی را در سایت نمایش داد |
| **C. فروشگاه متمرکز بر یک برند (بدون نمایندگی رسمی)** | خرده‌فروش تخصصی | پرریسک‌ترین حالت: بدون گواهی، ادعای اصالت ضعیف است و سئو هم سخت |

> **توصیه:** اگر سناریوی B یا C هستیم، اولین اقدام عملی، گرفتن **نامهٔ عاملیت/نمایندگی رسمی**
> و انتشار اسکن آن در سایت است. در بازار روغن موتور، «مدرک» مهم‌تر از «شعار» است.

### مزایا و معایب ذاتی مدل تک‌برندی

| مزیت | عیب / ریسک |
| --- | --- |
| کنترل کامل تجربهٔ مشتری (از صفحهٔ محصول تا بسته‌بندی) | **وابستگی کامل** به سرنوشت و اعتبار یک برند |
| برندینگ یکپارچه و ارزان‌تر (یک کتابچهٔ برند، یک لحن) | سبد محدود → امکان از دست دادن مشتری با بودجه/نیاز متفاوت |
| مشتری وفادار و دادهٔ غنی از رفتار خرید | **نمی‌توان در سئو روی عبارت‌های عمومی رقابت کرد** |
| حاشیهٔ سود بالاتر (مشتری برای «اسم» و «اطمینان» بیشتر می‌پردازد) | یک بحران (کمبود موجودی، شایعهٔ تقلب، تغییر بسته‌بندی برند) کل کسب‌وکار را می‌زند |
| عملیات ساده‌تر: یک تأمین‌کننده، یک انبار، یک فرآیند | نبود «فیلتر برند» → مشتری امکان مقایسه ندارد، باید مقایسه را **داخل برند** طراحی کنیم |

## ۳.۲ اقتصاد این کسب‌وکار: روغن موتور یک «اشتراک» است، نه یک کالا

این مهم‌ترین بینش کل سند است.

```
هر خودرو هر ۵٬۰۰۰ تا ۱۵٬۰۰۰ کیلومتر به روغن نیاز دارد.
میانگین پیمایش سالانهٔ یک خودروی شخصی در ایران ≈ ۱۵٬۰۰۰ کیلومتر
→ ۱ تا ۳ تعویض روغن در سال، برای همیشه، تا وقتی ماشین هست.
```

### محاسبهٔ سرانگشتی ارزش عمر مشتری (LTV)

| قلم | مقدار نمونه |
| --- | --- |
| حجم روغن هر تعویض (سواری) | ۴ لیتر |
| قیمت هر لیتر (فرضی) | ۳۰۰٬۰۰۰ تومان |
| فیلتر روغن + فیلتر هوا | ۲۵۰٬۰۰۰ تومان |
| **میانگین سبد هر تعویض** | **≈ ۱٬۴۵۰٬۰۰۰ تومان** |
| تعداد تعویض در سال | ۲ |
| **درآمد سالانه از یک مشتری** | **≈ ۲٬۹۰۰٬۰۰۰ تومان** |
| طول رابطه (سال) | ۵+ |
| **LTV خام** | **≈ ۱۴٬۵۰۰٬۰۰۰ تومان** |

> اگر LTV این عدد است، می‌توان برای CAC تا چند صد هزار تومان هزینه کرد.
> **نتیجهٔ استراتژیک:** هر ریالی که صرف «فروش اولین قوطی» شود و مشتری دوم نباشد، هدر رفته است.
> سایت باید روی **خرید دوم و سوم** طراحی شود، نه روی نرخ تبدیل خرید اول.

### سه اهرم رشد درآمد

1. **AOV ↑** — فروش سبد کامل سرویس (روغن + ۳ فیلتر + ضدیخ + قیف/دستکش) به‌جای یک قوطی
2. **تکرار ↑** — یادآور تعویض (پیامک/واتساپ)، اشتراک سرویس، برنامهٔ وفاداری
3. **دامنه ↑** — اضافه کردن موتور سیکلت، گیربکس، گریس، ناوگان و صنعتی (همان برند، سبد جدید)

## ۳.۳ سه مانع خرید آنلاین روغن موتور — و وظیفهٔ سایت در حل هرکدام

### مانع ۱: «نکنه تقلبی باشه؟» (اعتماد / اصالت)

بزرگ‌ترین مانع در بازار ایران. نمونهٔ تقلبی، روغن «تصفیه‌شدهٔ دوباره» در قوطی برند معتبر،
و چاپ و بسته‌بندی مشابه، واقعاً رایج است.

**وظیفهٔ سایت:**
- صفحهٔ اختصاصی **«اصالت کالا»** با این اجزا:
  - اسکن نامهٔ نمایندگی رسمی / گواهی توزیع
  - تصویر واقعی انبار و قفسه (نه عکس استوک)
  - ویدیوی بازکردن پالت و پلمپ
  - توضیح محل درج **شمارهٔ بچ و تاریخ تولید** روی قوطی برند ما (با عکس)
- **استعلام اصالت**: فرم/صفحه‌ای که مشتری کد یا شمارهٔ بچ را وارد کند و نتیجه بگیرد
  (حتی نسخهٔ ساده: «کد را بفرستید، ما از انبار استعلام و پاسخ می‌دهیم»)
- نمایش **تاریخ بچ واقعی** روی صفحهٔ محصول موجود در انبار — تقریباً هیچ رقیبی این کار را نمی‌کند
- **تعهد مکتوب**: «اگر اصالت محصول رد شد، هزینهٔ روغن + هزینهٔ تعویض + خسارت موتور طبق نظر کارشناس پرداخت می‌شود» — یک پیشنهاد جسورانه که عملاً ریسک ما را صفر و نرخ تبدیل را چند برابر می‌کند
- فاکتور رسمی با ذکر سریال/بچ، امکان استعلام از سامانهٔ مودیان

### مانع ۲: «کدوم روغن برای ماشین من؟» (اضطراب انتخاب)

**وظیفهٔ سایت:** ابزار **روغن‌یاب** (→ بخش ۳.۶). این هم ابزار UX است، هم بزرگ‌ترین موتور سئو.

### مانع ۳: «قیمت + حمل + دردسر»

**وظیفهٔ سایت:**
- قیمت شفاف، بدون «تماس بگیرید» برای کالاهای خرده
- محاسبهٔ هزینهٔ حمل بر اساس وزن و شهر **قبل از سبد** (روغن سنگین است: ۴ لیتر ≈ ۳٫۷ کیلو)
- آستانهٔ **ارسال رایگان** واقع‌بینانه (مثلاً خرید بالای X تومان یا ۲ قوطی ۴ لیتری)
- تحویل سریع محلی در شهر اصلی، ارسال باربری/تیپاکس برای شهرستان و اقلام ۲۰ لیتری به بالا
- پرداخت در محل برای سفارش‌های اول (کاهش ریسک ادراک‌شده)
- سیاست مرجوعی صریح: قوطی پلمب بازگشت‌پذیر است، باز شده خیر — و دلیلش را توضیح دهیم

## ۳.۶ ابزار «روغن‌یاب» — قلب تپندهٔ سایت تک‌برندی

### سه مسیر ورود (هر سه لازم است)

```
مسیر ۱ — بر اساس خودرو (مخاطب: رانندهٔ عادی)
  [سازنده] → [مدل] → [سال] → [موتور/حجم] → [بنزینی/دیزل] → نتیجه

مسیر ۲ — بر اساس استاندارد (مخاطب: تعمیرکار، مشتری آگاه)
  [ACEA C3] یا [API SP] یا [VW 507 00] یا [5W-30] → لیست محصولات منطبق

مسیر ۳ — بر اساس دفترچه (مخاطب: مشتری وسواسی)
  آپلود عکس صفحهٔ مشخصات روغن → اپراتور/هوش مصنوعی کد را استخراج می‌کند → پیشنهاد محصول
```

### صفحهٔ نتیجه باید دقیقاً این‌ها را بدهد

1. **پیشنهاد اول** (بهترین تطابق) + **پیشنهاد جایگزین** (اقتصادی‌تر یا موجود)
2. **چرا این روغن؟** — به زبان ساده: «چون موتور شما DPF دارد، کلاس C3 لازم است…»
3. **حجم مورد نیاز**: با تعویض فیلتر / بدون تعویض فیلتر
4. **کد مشخصات دفترچه** که این محصول پوشش می‌دهد
5. دکمهٔ **«افزودن سبد کامل سرویس»** (روغن + فیلتر روغن + فیلتر هوا)
6. سلب مسئولیت شفاف: «مبنای نهایی، دفترچهٔ راهنمای خودروی شماست. در صورت مغایرت با ما تماس بگیرید.»

### منبع دادهٔ سازگاری خودرو — چطور بسازیم؟

| منبع | کیفیت | هزینه |
| --- | --- | --- |
| دفترچه‌های راهنمای رسمی خودروساز | بهترین | زمان‌بر (باید دستی استخراج شود) |
| **Oil Selector / Lubricant Guide رسمی خودِ برند** | عالی و حقوقاً امن | رایگان اگر نمایندهٔ رسمی باشیم |
| دیتابیس‌های تجاری قطعات (مثل TecDoc/TecAlliance) | بسیار خوب | گران |
| کاتالوگ رقبا و منابع عمومی | متوسط | ریسک خطا |
| تجربهٔ تعمیرگاه‌های همکار | خوب برای اعتبارسنجی | رایگان |

> **قانون داده:** هر رکورد سازگاری باید `source` و `verified_at` داشته باشد.
> یک پیشنهاد اشتباه = یک موتور آسیب‌دیده = یک فاجعهٔ reputational برای سایت تک‌برندی.
> برای خودروهایی که دادهٔ مطمئن نداریم، صریح بنویسیم «نیازمند تأیید — با پشتیبانی تماس بگیرید»
> و **هرگز حدس نزنیم**.

## ۳.۷ صفحهٔ محصول — چک‌لیست کامل

یک صفحهٔ محصول روغن موتور در سایت تک‌برندی باید این بلوک‌ها را داشته باشد:

| بلوک | محتوا |
| --- | --- |
| **هدر** | نام، ویسکوزیته بزرگ، نوع پایه (فول سنتتیک)، انتخاب حجم (۱/۴/۵/۲۰ لیتر) با تغییر قیمت |
| **نشان‌های اعتماد** | اینماد، «نمایندگی رسمی»، «ضمانت اصالت»، «ارسال X روزه»، «فاکتور رسمی» |
| **مشخصات فنی سریع** | SAE، API، ILSAC، ACEA، تأییدیه‌های OEM (با تفکیک approved/meets) |
| **مناسب برای** | لیست کوتاه خودروها + لینک به صفحهٔ هرکدام |
| **ویژگی‌ها و مزایا** | ۴ تا ۶ مزیت با ترجمهٔ فایده برای مشتری (نه فقط اصطلاح فنی) |
| **جدول فنی کامل (TDS)** | ویسکوزیتهٔ ۴۰/۱۰۰°C، شاخص ویسکوزیته، نقطهٔ ریزش، نقطهٔ اشتعال، Noack، TBN، HTHS، چگالی |
| **دانلود** | TDS (PDF) و SDS (PDF) — اجباری برای B2B |
| **حجم روغن مورد نیاز خودروی شما** | محاسبه‌گر کوچک با انتخاب مدل |
| **باندل پیشنهادی** | فیلتر روغن، فیلتر هوا، فیلتر کابین، قیف، دستکش |
| **اطلاعات اصالت** | محل درج بچ‌نامبر روی قوطی (با عکس)، لینک استعلام |
| **شرایط نگهداری و انقضا** | ۵ سال، دور از آفتاب، دمای مناسب |
| **نظرات کاربران** | با امکان آپلود عکس |
| **سؤالات متداول همان محصول** | «آیا برای پژو ۲۰۶ مناسب است؟» «با فلان روغن چه فرقی دارد؟» |
| **CTA دوم** | «مطمئن نیستید؟ با کارشناس ما در واتساپ صحبت کنید» |
| **Schema.org** | `Product` + `Offer` + `AggregateRating` + `FAQPage` + `BreadcrumbList` |

## ۳.۸ بخش B2B — جایی که حجم واقعی پول است

خرده‌فروشی سواری برای برندسازی و نقدینگی خوب است، اما **حجم** در B2B است:
تعمیرگاه‌ها و تعویض‌روغنی‌ها، ناوگان‌های سبک و سنگین، شرکت‌های پخش، کارخانه‌ها، کشاورزی.

### چه چیزی لازم دارند که B2C ندارد؟

| نیاز | راه‌حل در سایت |
| --- | --- |
| قیمت عمده و پلکانی | پنل با ورود اختصاصی، نمایش قیمت پس از احراز |
| خرید سریع و تکراری | «سفارش مجدد» یک‌کلیکی، لیست خرید saved، ورود با SKU |
| اعتباری/نسیه | حد اعتبار، سررسید، حساب دفتری |
| فاکتور رسمی و الکترونیکی | اتصال به سامانهٔ مودیان، خروجی گروهی |
| بسته‌بندی ۲۰/۲۰۸ لیتری | قیمت متفاوت، حمل باربری |
| مشاورهٔ فنی ناوگان | حساب مدیر اختصاصی، پیشنهاد برنامهٔ روانکاری |
| گزارش مصرف | داشبورد خرید ماهانه بر اساس خودرو/راننده |
| تأییدیهٔ فنی برای مناقصه | دانلود TDS، گواهی کیفیت، نامهٔ انطباق |

### سه پلهٔ قیمت‌گذاری پیشنهادی

```
پلهٔ ۱ — تعمیرگاه کوچک   : خرید ≥ ۵ کارتن   → تخفیف A + ارسال رایگان منطقه‌ای
پلهٔ ۲ — تعمیرگاه/ناوگان  : خرید ≥ ۲۰۰ لیتر  → تخفیف B + حساب اعتباری ۳۰ روزه
پلهٔ ۳ — صنعتی/پخش‌کننده  : خرید بشکه/IBC     → قیمت توافقی (RFQ)
```

## ۳.۹ عملیات و لجستیک (چیزهایی که در سایت روغن فرق دارد)

| موضوع | واقعیت |
| --- | --- |
| **وزن** | ۴ لیتر روغن ≈ ۳٫۷ کیلوگرم. یک کارتن ۴×۴ لیتری ≈ ۱۵ کیلو. هزینهٔ حمل وزن‌محور است |
| **نشتی** | بسته‌بندی باید شامل پلمپ حرارتی، کیسهٔ ضدنشت، کارتن دوبل و ضربه‌گیر باشد. نشتی = مرجوعی قطعی |
| **کانال حمل** | پست/پیک برای ≤۵ لیتر درون‌شهری؛ تیپاکس/باربری برای شهرستان و اقلام سنگین |
| **کالای خطرناک** | روغن موتور در اکثر سیستم‌های حمل «خطرناک» محسوب نمی‌شود، ولی SDS باید در دسترس باشد |
| **دما** | انبار باید دور از یخ‌زدگی و آفتاب مستقیم باشد؛ چرخهٔ انجماد-ذوب کیفیت را تغییر می‌دهد |
| **FEFO** | خروج بر اساس «اول انقضا، اول خروج» نه FIFO — چون تاریخ بچ روی اعتماد اثر دارد |
| **مرجوعی** | قوطی پلمب = قابل برگشت؛ باز شده = غیرقابل برگشت (با دلیل بهداشتی/فنی صریح) |
| **موجودی** | تنوع ویسکوزیته × حجم × بسته‌بندی = انفجار SKU. باید «حجم پیش‌فرض» را محدود کرد |

## ۳.۱۰ الزامات قانونی و مجوزها (ایران)

| مجوز / الزام | مرجع | وضعیت |
| --- | --- | --- |
| **اینماد (نماد اعتماد الکترونیکی)** | مرکز توسعه تجارت الکترونیکی | **الزامی** برای درگاه پرداخت مستقیم |
| **کد مالیاتی / پروندهٔ مالیاتی** | سازمان امور مالیاتی (tax.gov.ir) | **الزامی** — پیش‌نیاز اینماد ستاره‌دار و درگاه |
| **درگاه پرداخت** | PSP بانکی یا پرداخت‌یار | الزامی برای فروش آنلاین |
| **پروانهٔ کسب از اتحادیهٔ کسب‌وکارهای مجازی** | اتحادیهٔ کشوری | برای فعالیت رسمی توصیه/الزام |
| **نماد ساماندهی رسانه‌های دیجیتال** | وزارت ارشاد | برای محتوای رسانه‌ای؛ تقویت‌کنندهٔ اعتماد |
| **SSL / HTTPS** | — | الزامی |
| **سامانهٔ مودیان و صورتحساب الکترونیکی** | سازمان امور مالیاتی | **برای B2B عملاً الزامی** |

| **استاندارد محصول / برچسب اصالت** | سازمان ملی استاندارد ایران | برای واردات و تولید |

> ارقام و رویه‌ها تغییر می‌کنند. قبل از اجرا، آخرین وضعیت را از مراجع رسمی استعلام کنید.

## ۳.۱۵ جمع‌بندی: پنج کار حیاتی که سایت تک‌برندی باید انجام دهد

1. **ابراز اصالت کند** — مدرک، بچ‌نامبر، ضمانت مکتوب. در روغن موتور، اعتماد خودِ محصول است.
2. **انتخاب را آسان کند** — روغن‌یاب سه‌مسیره + حجم دقیق + سبد سرویس کامل.
3. **مالک جست‌وجوی تخصصی شود** — نه «خرید روغن موتور»، بلکه «روغن موتور دنا EF7»، «ACEA C3 چیست»، «VW 507 00».
4. **خرید تکراری بسازد** — یادآور تعویض، گاراژ من، اشتراک سرویس. LTV اینجا ساخته می‌شود.
5. **B2B را جدا ببیند** — پنل عمده، قیمت پلکانی، فاکتور رسمی، بسته‌بندی بشکه‌ای.
